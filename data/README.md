# Data

Data moves through five layers. Only the `curated/` files are edited by hand; everything
else is either a frozen input or regenerated by a `dhlife` command.

| layer | content | how it changes |
|---|---|---|
| `sources/` | Candidate projects from each source, plus the frozen Google Sheet snapshot in `sources/raw/`. See [`sources/README.md`](sources/README.md). | `dhlife sources`, `dhlife crawl` |
| `curated/` | `projects.csv`: the 284 projects and their manual status assessment (16 columns). `last_seen_corrections.csv`: manually verified last-seen dates of discontinued projects. | **by hand** |
| `processed/` | `projects_archive_2026.csv`: `projects.csv` plus the Wayback/live-check columns. `unavailable_projects.csv`, `status_discrepancies.csv`: generated by `dhlife stats`. | `dhlife archive-check`, `dhlife stats` |
| `release/` | The files published on Zenodo. Never edited; a new release is a new file. | `dhlife release --version NN` |
| `qualitative/` | Anonymised survey answers of live (`progetti-vivi.csv`) and discontinued (`progetti-morti.csv`) projects. | by hand |

Column meanings: [`../docs/data_dictionary.md`](../docs/data_dictionary.md).

`archive-check` takes about an hour, because of the Internet Archive rate limits. It reuses
the values of the previous run (`--previous`) when the Wayback Machine cannot be reached, so
a failed request never blanks a cell.

`processed/unavailable_2026-06-14.csv` is a legacy file: the hand-made list of 49
unavailable projects used for the June 2026 draft. It cannot be regenerated; the current,
reproducible list is `processed/unavailable_projects.csv` (53 projects).
