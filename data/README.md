# Data

Data moves through five layers. Only the `curated/` files are edited by hand; everything
else is either a frozen input or regenerated by a `dhlife` command.

| layer | content | how it changes |
|---|---|---|
| `sources/` | Candidate projects from each source, plus the frozen Google Sheet snapshot in `sources/raw/`. See [`sources/README.md`](sources/README.md). | `dhlife sources`, `dhlife crawl` |
| `curated/` | `italian_dh_projects.csv`: the 284 projects and their manual status assessment (16 columns). `last_seen_manual_corrections.csv`: manually verified last-seen dates of discontinued projects (extracted once from the sheet's `dead_projects` tab; one row, *Arts 01*, is for a project later dropped from the list and matches nothing). | **by hand** |
| `processed/` | `italian_dh_projects_wayback_check_2026.csv`: `italian_dh_projects.csv` plus the Wayback/live-check columns. `unavailable_projects_2026.csv`, `live_status_vs_manual_check_2026.csv`: generated by `dhlife stats`. | `dhlife archive-check`, `dhlife stats` |
| `release/` | The files published on Zenodo: `…_20250530_v01.csv` (AIUCD 2025 paper) `…_20260614_v03.csv` (Zenodo v1.2.0) and `…_20261017_v04.csv` ([10.5281/zenodo.23434566](https://doi.org/10.5281/zenodo.23434566), UTF-8, column names of the Zenodo documentation). Never edited; a new release is a new file. | `dhlife release --version NN` |
| `qualitative/` | Anonymised survey answers of live (`survey_active_projects.csv`) and discontinued (`survey_discontinued_projects.csv`) projects. | by hand |

Column meanings: [`../docs/data_dictionary.md`](../docs/data_dictionary.md).

`archive-check` takes about an hour, because of the Internet Archive rate limits. It reuses
the values of the previous run (`--previous`) when the Wayback Machine cannot be reached, so
a failed request never blanks a cell.

`processed/unavailable_projects_manual_2026-06-14.csv` is a legacy file: the hand-made list of 49
unavailable projects used for the June 2026 draft. It cannot be regenerated; the current,
reproducible list is `processed/unavailable_projects_2026.csv` (53 projects).
