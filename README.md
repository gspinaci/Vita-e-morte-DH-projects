Github repository of the dataset created for the paper "Life and Death of DH Projects: A Preliminary Investigation of Their Lifecycles in Italy" presented at the "XIV convegno annuale dell’Associazione per l’Informatica Umanistica e la Cultura Digitale (AIUCD)". Then, the repository was used to work on an extension of this paper, called "Life and Death of DH Projects: An Investigation of Their Lifecycles in Italy". 

Find the output dataset at `DH_Projects_Survey_20260614_v03.csv`

The dataset has been published on [Zenodo](https://doi.org/10.5281/zenodo.23079655) under the CC-BY-4.0 license.
